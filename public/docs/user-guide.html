1) Overview: Roles and Responsibilities

  • Admin: Full system manager. Jobs, invoicing, payslips, documents, exports, payments.
  • Agent (Interpreter): Accept assignments, perform service, submit timesheets & expenses, get payslip.
  • Agent (Translator): Accept assignments, handle documents, upload deliverables, get payslip.
  • Client: Receive invoices & attachments, review and pay, request receipts.

2) Access & Navigation

  • Jobs: Create & manage Interpreter/Translator jobs.
  • Accounting Reports: “Not Invoiced” filtering; create client invoices from selected jobs.
  • Invoices: Create, update, preview, and send; attach documents; VAT & parking; v2/v3 templates.
  • Payslips/Agent Invoices: Generate agent-side invoices; mark paid; export/email.
  • Documents: Attach timesheets (Interpreter) or deliverables (Translator).
  • Exports: Download CSV/Excel for reconciliation and reporting.

3) Admin Guide

A. Creating Jobs

  • Interpreter: client, language, date/time, location, rate, VAT, references, notes; assign agent.
  • Translator: client, language pair, service type, rate basis, VAT, references; assign agent; upload source docs.

B. Not Invoiced → Create Client Invoice (Batch)

  • Filter; select jobs; create ClientInvoice + ClientInvoiceItem(s) with job_type set.
  • Choose template v2/v3; review VAT & totals; attach documents.

C. Manual Invoice Edits

  • Add/remove items; set job_id & job_type; update metadata (dates, references, notes).
  • Totals and parking recomputed; header summary on first item (v2).

D. Send Client Invoices

  • Recipients, CC/BCC, subject/message overrides.
  • Attach Interpreter timesheets or Translator deliverables based on job_type.

E. Payments & Agent Payslips

  • Mark client invoices paid; export for reconciliation.
  • Generate agent invoices/payslips; email/export; mark agent payments processed.

4) Agent Guide

Interpreter Agent

  • Accept assignments; perform service; submit timesheets/expenses; review payslip.

Translator Agent

  • Review scope; download source docs; upload deliverables; review payslip.

5) Client Guide

  • Receive invoice emails with attachments; review references, VAT, totals; pay and request receipts.

6) Features & Possibilities

  • Batch invoicing; multi-job v3 invoices; single-job v2.
  • job_type-aware documents and attachments.
  • Rich metadata per item; header summaries (v2); exports for reporting.

7) Operational Checklists

Admin

  • Confirm job completion & documents attached; validate VAT & totals; choose template; send.

Agents

  • Interpreter: submit timesheet/expenses promptly.
  • Translator: upload clean final deliverables.

Client

  • Review and pay; request receipts/statements.

8) Troubleshooting & FAQs

  • Job missing in “Not Invoiced”: check filters; verify job_id/job_type; ensure not already invoiced.
  • Attachments missing: ensure correct job_type and documents attached to the job.
  • VAT/Total discrepancies: confirm item VAT flags; template (v2/v3); parking logic.
